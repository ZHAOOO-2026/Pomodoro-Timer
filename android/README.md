# 番茄自习室 Android

原生 Android 初版，使用 Kotlin、Jetpack Compose 与 Material 3。

## 页面

- 番茄钟：专注/短休息/长休息计时；开始、暂停；倒计时结束记一轮。
- 自习室：查看演示房间、加入房间、创建房间入口。
- 计划：任务勾选和添加。
- 打卡：连续打卡状态与月历视觉原型。
- 统计：专注概况与周趋势图。

目前房间在线人数、打卡记录和统计均为本地演示状态，未连接账号或云端 API。下一阶段可接入现有功能说明中规划的后端。

## 打开项目

用 Android Studio 打开此 `android` 文件夹，安装 Android SDK 35，并通过 Gradle Sync 后运行 `app`。最低支持 Android 8.0（API 26）。

包名：`com.tomato.study`  
版本：`0.1.0`
